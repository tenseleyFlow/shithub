shithub

GitHub. Open source. Without Copilot.

{{/* Landing page — marketing copy for the v1 launch. Honest and concise; the heavy "what works / what doesn't" lives in the README and docs site, not on the homepage. */}}

A self-hostable git forge that aims to look and feel like GitHub. AGPL-licensed, written in Go, no AI training on your code, no Copilot. Sign up to host code here, or run your own instance from the source.

  • Repos, issues, pull requests Branch protection, reviews, status checks, three merge methods.
  • Code browsing Tree, blob with syntax highlighting, blame, commit history, diffs.
  • Search Code, repos, users, issues — with the operators you'd expect.
  • Webhooks & notifications HMAC-signed deliveries with auto-retry, in-app inbox, email fan-out.
  • Orgs, teams, scoped tokens Role-based access; PATs with revocable scopes.
  • Self-host first One binary, Postgres, S3-compatible storage, Caddy at the edge.
